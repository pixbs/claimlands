What this is

This page proves the per-pull-request deployment works end to end. The pipeline was built before the renderer on purpose, so that when the preview harness lands there is already somewhere for it to go — and so that a broken deployment is never confused with a broken renderer.

The WebGPU planet viewer replaces this page in issue #44.

Why a preview at all

The gates prove a change is self-consistent. None of them prove it is right. Cover scattered evenly and cover properly clumped produce identical share statistics; continents banded around the equator satisfy every assertion about a land-fraction quantile. Those are five-second observations, if anyone can see them.
